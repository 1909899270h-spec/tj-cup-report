# 足协杯战报撰写规范（据宣传部《战报撰写指导说明》整理）

## 标题

```
足协杯丨湄公河小兽2:0西北联摘得桂冠，单君博梅开二度尽显神锋风采
```

- 前缀 **`足协杯丨`** 不能漏。
- 结构：`比分 +（出线形势）+ 全场关键事件 1-2 个`。
- 关键事件可用词：破门、绝杀、梅开二度、帽子戏法、大四喜、独中N元、制胜、打入唯一进球、
  世界波、多点开花、让二追三、逆转。

## 比分

```
比分：湄公河小兽2:0西北联
```

- 整篇的比分一律**英文冒号** `:`（不是全角的 `：`）。
- 队名写**全称**，不加"队"字（队名本身含"队"的除外，以秩序册为准）。

## 赛事简讯

- 开头固定句式：
  `XX年XX月XX日XX:XX，同济大学第XX届足协杯（A组小组赛／1/4决赛／半决赛／决赛），A队对阵B队。`
- 时间写**计划开球时间**（8:30 / 9:30 / 10:30 / 11:30），不写实际开球时间。
- 简讯里**不写具体分钟**，只用"上半场、下半场、易边再战"这类词。
- 结尾一句收束（冠军/逆转/晋级/三分）。

## 双方首发

```
湄公河小兽：
12-林睿源 22-王圣元 30-刘晟 3-刘晋铭 1-朱学昊 11-单君博 19-董世隆
```

- 格式 `号码-姓名`，**直接从名单公示复制**，别手打。
- **首发 8 人**，不多不少；替补不写。
- 场上号码与报告单不一致时，以比赛报告单为准。

## 比赛进程

- 官方时间轴素材拼图（本 skill 的 `assets/timeline` 就是原版素材）。
- 文字 35 号、等线、黑色；圈内分钟数白色。
- 左队文字**右对齐**贴图标，右队文字**左对齐**。
- 进球行要带当时比分：主队写最左，客队写最右。
- 乌龙球有专用素材（`乌龙（左队得分）` / `乌龙球（右队得分）`）。

## 精彩瞬间

基本句式：

```
第16分钟，湄公河小兽王圣元送出精妙直塞，单君博不停球推射远角先拔头筹！
（视频1）
```

- "第XX分钟"用阿拉伯数字，**不要写 16' 或 16min**。
- "X分钟后"里的 X 用**汉字**（"一分钟后"）。
- 构成：时间 + 球队/球员 + 射门方式（单刀/补射/头球/远射/一条龙/接传中…）
  + 结果（破门/被扑出/滑门而过…）+ 形势（打破僵局/扳平/杀死悬念/绝杀…）+ 比分 `(a:b)`。
- **进球语句整句加粗**。
- 认不出人时一律写"XX队球员/门将"，别硬编。
- 视频总数（全部进球 + 精彩瞬间）**保持 6–8 个**，最多不超过 10 个；每段 7–10 秒，
  横屏，进球后庆祝尽量录完整（供五佳球素材）。

## 拍摄与数据来源

- 赛前拍两队合照（11 人制中圈内）；比赛中在球门内抓拍（视频，勤拍勤删）。
- 进球没抓到的补救：用进球后的**庆祝照片**替代。
- 赛后找第四官员核对并拍摄**比赛报告**，照片直接发群里。
- 从实际开球时间 + 手机录制时间推算"第 XX 分钟"。

## 纪律

- 至少提前一天发布排班；赛前 5 分钟到场，问清自己负责的半区。
- 战报当天 **19:00 前**发群；晚于 19:00 工资减半。
